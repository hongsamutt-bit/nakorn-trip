# นครทริป (Nakhon Trip)

เว็บแอปสำหรับมือถือ ช่วยให้ทุกวัยเตรียมตัวไปไหว้พระในจังหวัดนครปฐม ด้วยเรื่องราว บทสวด และ **แบบจำลอง 3 มิติ** ที่หมุนดูได้รอบทิศ

A mobile-first web app for visiting temples in Nakhon Pathom, Thailand — history, chants and interactive 3D models built with three.js.

## สถานที่ในแอป

| วัด | จุดเด่นในแบบจำลอง 3D |
| --- | --- |
| **พระปฐมเจดีย์** | องค์ระฆังทอง บัลลังก์ เสาหาน ปล้องไฉน ยอดมงกุฎ ระเบียงคด วิหารสี่ทิศ พระร่วงโรจนฤทธิ์ |
| **วัดไผ่ล้อม** | อุโบสถหน้าบันทอง ซุ้มประตูยักษ์ วิหาร ระเบียงพระ พระองคุลิมาล ศาลาหลวงพ่อพูล โถงกวนอิม |
| **พระประโทณเจดีย์** | ฐานอิฐทวารวดีซ้อนชั้น ปรางค์ขาวบนยอด บันไดเหล็ก ศาลคุณยายหอมและตุ๊กตาเป็ด |

## ความสามารถ

- สำรวจ 3D: หมุน ซูม เปลี่ยนแสงกลางวัน/ยามเย็น/กลางคืน และแตะหมุดเพื่ออ่านข้อมูล
- คู่มือเดินชม ประวัติ บทสวดพร้อมปุ่มคัดลอก และลิงก์แหล่งอ้างอิงของแต่ละวัด
- เข้าถึงได้ทุกวัย: ปรับขนาดตัวอักษร 3 ระดับ ธีมสว่าง/มืด ปุ่มขนาดใหญ่ รองรับคีย์บอร์ดและโปรแกรมอ่านหน้าจอ
- บัญชีผู้ใช้ กระเป๋าเครดิต **จำลอง** บัตรเข้าชม 3D และลิงก์แชร์ชั่วคราวให้เพื่อน (ไม่มีการชำระเงินจริง)

## วิธีรัน

ต้องมี **Node.js 22.13 ขึ้นไป** (ใช้ฐานข้อมูล `node:sqlite` ที่มากับ Node ไม่ต้องติดตั้งฐานข้อมูลเพิ่ม)

```bash
npm install
npm run dev
```

เปิด <http://localhost:3000> (บน Windows ดับเบิลคลิก `START-LOCAL.cmd` ได้เลย)

รันแบบ production:

```bash
npm run build
npm start
```

ฐานข้อมูลจะถูกสร้างอัตโนมัติที่ `data/nakorn-trip.sqlite` ในครั้งแรกที่ใช้งาน ลบโฟลเดอร์ `data/` เพื่อล้างข้อมูลทั้งหมด

## โครงสร้างโปรเจกต์

```
app/
  page.tsx            หน้าแอปทั้งหมด (หน้าแรก วัด กระเป๋า บัตร ตั้งค่า)
  temples.ts          ข้อมูลวัด: ประวัติ คู่มือ บทสวด แหล่งอ้างอิง
  globals.css         ธีม สี ฟอนต์ (สว่าง/มืด, ขนาดตัวอักษร)
  mockup.css          กรอบโทรศัพท์เมื่อเปิดบนจอคอมพิวเตอร์
  api/[...path]/      เส้นทาง API
server/
  api.ts              ระบบสมาชิก เครดิตจำลอง บัตรเข้าชม ลิงก์แชร์
  scene-html.ts       หน้า HTML ของตัวชม 3D
db/
  index.ts            ฐานข้อมูล SQLite (node:sqlite)
  schema.sql          โครงสร้างตาราง
public/viewer/
  scene.js            ตัวชม 3D (กล้อง แสง หมุด)
  kit.js              ตัวช่วยสร้างโมเดล (อิฐ ปูน กระเบื้อง หลังคาไทย ต้นไม้)
  sites/*.js          โมเดลของแต่ละวัด
  vendor/             three.js (MIT)
```

## เพิ่มวัดใหม่

1. เพิ่มข้อมูลวัดใน `app/temples.ts`
2. สร้างไฟล์ `public/viewer/sites/<id>.js` ที่ export `build(kit)` และคืนค่า `hotspots` (ดูตัวอย่างจากไฟล์ที่มีอยู่)
3. ลงทะเบียนใน `SITES` ที่ `public/viewer/scene.js`
4. ใส่เครดิตภาพใน `public/asset-credits.txt`

## เทคโนโลยี

Next.js 16 · React 19 · TypeScript · three.js · SQLite (`node:sqlite`) · ฟอนต์ IBM Plex Sans Thai Looped และ Noto Serif Thai

## ข้อจำกัดและเครดิต

- โมเดล 3D เป็นงานสร้างเชิงศิลป์จากภาพอ้างอิง ตำแหน่งอาคารและหมุดเป็นการประมาณ ไม่ใช่ข้อมูลสำรวจหรือแผนผังทางหนีไฟ
- เครดิตเป็นระบบจำลองเพื่อการศึกษา ไม่มีการเรียกเก็บเงินจริง
- เครดิตภาพและสัญญาอนุญาตอยู่ใน [`public/asset-credits.txt`](public/asset-credits.txt) แหล่งข้อมูลของแต่ละวัดอยู่ใน `app/temples.ts` และแสดงในแอป
